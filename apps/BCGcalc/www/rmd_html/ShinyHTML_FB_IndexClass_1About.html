Purpose

The BCG calculator requires the inclusion of Index Name and Index Class fields in the input file (otherwise the R code won’t know which BCG rules to apply).

There is a new statewide BCG model for Oregon and Washington that supersedes the previous Pacific Northwest Maritime Region (PNMR) model, which only covered the western ecoregions.

The statewide classification scheme is based on Omernik Level 4 ecoregion, NHDPlus v2 slope and collection method (targeted riffle or random transect).

Columns with Index_Name and Index_Class must be included in the input file (they tell the R code which rules to apply to each sample).

Index_Name = BCG_ORWA_v1_Bugs500ct

Index_Class entries must match one of the options below:

INDEX_CLASS
Foothills_Multihab
Foothills_Riffle
Lowlands_Multihab_HiGrad
Lowlands_Riffle
MountainCold_Multihab
MountainCold_Riffle
NBR_Riffle
Xeric_Multihab
Xeric_Riffle

When assigning samples to Index_Class:

  • Foothills, Lowlands, MountainCold, Northern Basin and Range (NBR) and Xeric are based on which Omernik Level 4 ecoregion the site is located in. Download translator sheet here.

  • Collection method (Multihab vs. Riffle) is self-explanatory

    • Riffle = targeted riffle method used by ORDEQ, King and Snohomish County and others

    • Multihab = random transect method used by WA_ECY

  • Gradient (which is only used for the Lowlands_Multihab classes) is based on NHDPlus v2 percent slope

    • LoGrad (low gradient) < 1%

    • HiGrad (high gradient) >= 1%

If you prefer to use the old Pacific Northwest Maritime Region (PNMR) model, there are two versions:

  • Index_Name = BCG_MariNW_v2_Bugs500ct

  • Index_Name = BCG_MariNW_Bugs500ct

They are the same EXCEPT we removed the Level 6 rule for number of total individuals from the BCG_MariNW_v2_Bugs500ct model, since that rule was causing samples to be bumped to Level 6 that the BCG workgroup thought were better suited to BCG level 5.

Index_Class entries for either PNMR model must match one of the options below:

INDEX_CLASS
HiGrad-LoElev
HiGrad-HiElev
LoGrad-LoElev

The classification thresholds are 1% for gradient (NHDPlus v2 percent slope) and 750-m for elevation.
